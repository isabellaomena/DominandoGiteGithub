## Sobre o projeto

Este projeto foi desenvolvido para praticar os principais conceitos de Git e GitHub, além de desenvolver uma página utilizando HTML e CSS.

## Tema do projeto e o que tem em cada página

O tema do projeto é “Hobbies”, tendo em cada página o hobby preferido de cada integrante da equipe.

## Tecnologias utilizadas

- HTML
- CSS
- Git
- GitHub

## Estrutura do projeto

O projeto é composto pelos seguintes arquivos:

- `index.html` — estrutura da página;
- `style.css` — estilização da página;
- `README.md` — documentação do projeto.

## Como executar

1. Clone este repositório;
2. Abra a pasta do projeto;
3. Abra o arquivo `index.html` em um navegador;
4. Explore a página.

## Aprendizados

Durante o desenvolvimento deste projeto, foram praticados conceitos relacionados ao controle de versão e ao uso do GitHub para armazenar e organizar projetos.
